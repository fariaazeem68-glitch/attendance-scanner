# Digital Attendance Scanner

A web-based attendance system that marks student attendance using **Face Recognition** (Teachable Machine) and **Student ID**.

## Features
- Face recognition using webcam (Teachable Machine)
- Manual Student ID marking
- Live Attendance Dashboard
- Present / Absent status with timestamp
- Works offline (after first load)

## How to Use
1. Open the website
2. Click **Start Camera**
3. Look at the camera → system detects the student
4. Click **Mark Present**
5. Check the Dashboard for records

## Tech Stack
- HTML, CSS, JavaScript
- Teachable Machine (TensorFlow.js)
- LocalStorage
